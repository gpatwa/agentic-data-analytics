Nothing here has been run. See `docs/design/CONNECT_PRODUCT_RUN_ROLLBACK_CHECK_PLAN.md`.

Registration, fixture, read-backs and teardown are **the same statements as the end-to-end check** (`CONNECT_PRODUCT_RUN_E2E_STATEMENTS.md`), with a new run suffix; they are repeated here so this file is complete. The stop rule that refuses any statement that would change an account's or a user's network policy applies to all of them.
